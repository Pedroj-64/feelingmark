# Contributing / Contribuir

**EN** — Issues and PRs are welcome. Run `pnpm install`, then `pnpm test && pnpm typecheck` before opening a PR. Keep changes small and focused; add a test for new server logic. Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`...). New language: copy `apps/mobile/src/i18n/en.ts` to `xx.ts` (TypeScript will tell you what is missing) and register it in `i18n/index.ts`. Read `DESIGN.md` before touching the UI.

**ES** — Se aceptan issues y PRs. Ejecuta `pnpm install` y luego `pnpm test && pnpm typecheck` antes de abrir un PR. Cambios pequeños y enfocados; añade un test para la lógica nueva del servidor. Commits convencionales (`feat:`, `fix:`, `docs:`...). Nuevo idioma: copia `apps/mobile/src/i18n/en.ts` a `xx.ts` (TypeScript te dirá qué falta) y regístralo en `i18n/index.ts`. Lee `DESIGN.md` antes de tocar la interfaz.
