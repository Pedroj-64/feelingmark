# Deploy on Cloudflare / Despliegue en Cloudflare

## English

One Worker serves the API **and** the web client. Photos go to **R2**, metadata to **D1** (SQLite). No server to maintain.

```bash
pnpm install
cd apps/server && npx wrangler login        # once
npx wrangler secret put AUTH_TOKEN          # paste a long random token (openssl rand -hex 24)
cd ../.. && pnpm deploy:cloudflare
```

R2 must be enabled once in the Cloudflare dashboard (*R2 Object Storage*; Cloudflare may ask for a payment method even though the free tier is enough) and the bucket created: `npx wrangler r2 bucket create feelingmark-photos`. The first deploy creates the D1 database automatically. Wrangler prints the URL (`https://feelingmark.<you>.workers.dev`): open it, go to **Settings** and enter that URL and your token. Do the same in the Android app.

What changes compared with the Docker server:
- **Thumbnails** are generated by the app when you upload (the Worker has no `sharp`). Photos uploaded by other means show the full image in the calendar.
- **Video recap is not available** (no `ffmpeg` in Workers); the endpoint answers `501`.
- Free tier: R2 ~10 GB and no egress fees; D1 5 GB. Check Cloudflare's current limits.
- Test locally without touching your account: `cd apps/server && echo AUTH_TOKEN=dev > .dev.vars && npx wrangler dev --local`.

## Español

Un solo Worker sirve la API **y** el cliente web. Las fotos van a **R2** y los metadatos a **D1** (SQLite). Sin servidor que mantener.

```bash
pnpm install
cd apps/server && npx wrangler login        # una vez
npx wrangler secret put AUTH_TOKEN          # pega un token largo y aleatorio (openssl rand -hex 24)
cd ../.. && pnpm deploy:cloudflare
```

Hay que activar R2 una vez en el panel de Cloudflare (*R2 Object Storage*; puede pedir un método de pago aunque la capa gratuita alcance) y crear el bucket: `npx wrangler r2 bucket create feelingmark-photos`. El primer despliegue crea solo la base D1. Wrangler imprime la URL (`https://feelingmark.<tu-usuario>.workers.dev`): ábrela, entra en **Ajustes** y escribe esa URL y tu token. Haz lo mismo en la app Android.

Qué cambia frente al servidor con Docker:
- Las **miniaturas** las genera la app al subir (el Worker no tiene `sharp`). Las fotos subidas por otro medio muestran la imagen completa en el calendario.
- **El resumen en video no está disponible** (no hay `ffmpeg` en Workers); el endpoint responde `501`.
- Capa gratuita: R2 ~10 GB y sin cobro de salida; D1 5 GB. Revisa los límites actuales de Cloudflare.
- Prueba local sin tocar tu cuenta: `cd apps/server && echo AUTH_TOKEN=dev > .dev.vars && npx wrangler dev --local`.
